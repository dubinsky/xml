= org.podval.xml
:toc:
:toclevels: 3

Dialect-aware XML for Scala 3: parse, write, transform, and bind documents.

Maven coordinates: `org.podval:org.podval.xml:0.0.2`

----
implementation 'org.podval:org.podval.xml:0.0.2'
----

`zio-blocks-schema` and `zio-blocks-schema-xml` come in transitively (`XmlCodec`, `XmlParser`).
HTML and Scala XML ASTs need an extra dependency, not pulled in by default.
Bring their givens in with `import Html.given` / `import ScalaXml.given`:

----
implementation "dev.zio:zio-blocks-html_3:0.0.51"
implementation 'org.scala-lang.modules:scala-xml_3:2.4.0'
----

== Packages

`org.podval.xml`:: AST (`XmlAst`) over ZIO Blocks XML, Scala XML, and HTML; SAX parser (CDATA preserved) and builder, both over any `XmlAst`; writer; `Xml2Html`; Schema-derived document binder (`XmlCodec`).
`org.podval.metadata`:: multilingual `Name` / `Names` / `Language` catalogs.
`org.podval.store`:: in-memory named tree and path `resolve`.

== Parse and catalogs

`XmlParser` loads from a string, URL, file, or classpath resource into any `XmlAst` (`E` from the expected type, or `given Xml`). `parseXml(s)` infers ZIO Blocks XML. For HTML or Scala XML, import `Html.given` / `ScalaXml.given`. `xi:include` is not expanded (`xi:include/@href` stays a page ref). `parseXml` returns the document element; `parseXmlDocument` keeps the declaration, doctype, and comments/PIs before and after the root so a file can round-trip through the writer.

A catalog is a named wrapper whose children are one record type: `codec.decodeCatalog(root, name)` or `XmlParser.parseCatalog(resource, name, codec)`.

== XInclude

This library does not expand `xi:include`. JDK SAX is XInclude-unaware. Publisher `store`/`collection` indexes treat `xi:include/@href` as a child page reference. Xerces nested `xml:base` is still wrong (https://issues.apache.org/jira/browse/XERCESJ-1102); see CHANGELOG.

== Codec

`XmlCodec` is a ZIO Schema `Deriver` that binds Scala records to XML documents (unwrapped sibling sequences, attributes on leaf records). Identity fields are canonical `XmlTree` (`Xml.Element`); leftover parent content is an error. Binding hints are `@Modifier.config` (`XmlCodec.Attribute`, `XmlCodec.Element`, `XmlCodec.Text`).

./gradlew build
